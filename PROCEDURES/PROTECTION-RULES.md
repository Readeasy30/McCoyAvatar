# PROTECTION RULES

1. Working code is valuable.
2. Diagnose before changing.
3. Back up before destructive changes.
4. Prefer repair over rebuild.
5. Never delete uncertain files.
6. Archive before removal.
7. Test changes before production.
8. Verify deployment after release.
9. Record failures and successful repairs.
10. Convert important experience into reusable company knowledge.
11. GitHub must receive important completed work.
12. Local machines are temporary workbenches.
