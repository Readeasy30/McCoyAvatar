# 📖 Executive Avatar Factory Operation Manual

## 🚀 Quick Launch Commands
*   **System Diagnostics:** Double-click `Startup.bat` to run local tests.
*   **Visual Control Panel:** Open `index.html` in your browser to view your live health statuses.

## ⚙️ Core Automation Scripts
1.  **Draft Campaigns:** Run `python TOOLS/campaign_compiler.py` to generate new multi-format copywriting assets.
2.  **Deploy Channels:** Run `python TOOLS/automate_channels.py` to trigger your open-source email engine and social media staging payloads.
3.  **Run System Tests:** Run `python test_suite.py` to verify all 4 core logic pipelines pass with zero local errors.
