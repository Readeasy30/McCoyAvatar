## RULE

Do not install every tool simply because it is mentioned in research.

For every candidate tool record:

- Official repository
- Purpose
- License
- Hardware requirements
- Windows compatibility
- Dependencies
- Maintenance/activity
- Whether it is actually needed
- Whether it replaces another tool
